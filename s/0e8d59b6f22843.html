জাহান্নামীদের খাদ্য সম্পর্কে কুরআনের বক্তব্যে কি স্ববিরোধিতা আছে?

Response to Anti-Islam·মুহাম্মাদ মুশফিকুর রহমান মিনার·Nov 19, 2020

দোজখের খাবার কি হবে ? – শুধুই বিষাক্ত কাটাগাছ (Quran 88:6), শুধুই পুঁজ (Quran 69:36) নাকি বিস্বাদ যাকুম ফল (Quran 37:66) !

মূলত প্রসঙ্গ ছাড়া উদ্ধৃত করবার ফলে আপাতদৃষ্টিতে মনে হচ্ছে উল্লেখিত আয়াতগুলোতে স্ববিরোধিতা আছে। কিন্তু প্রসঙ্গসহ পড়লে বোঝা যায় এখানে কোনোই স্ববিরোধিতা নেই।

আল কুরআনে সুরা আস সফফাতে বলা হয়েছেঃ

( 52 ) সে বলত, তুমি কি বিশ্বাস কর যে,

( 53 ) আমরা যখন মরে যাব এবং মাটি ও হাড়ে পরিণত হব, তখনও কি আমরা প্রতিফল প্রাপ্ত হব?

( 54 ) আল্লাহ বলবেন, তোমরা কি তাকে উকি দিয়ে দেখতে চাও?

( 55 ) অপর সে উকি দিয়ে দেখবে এবং তাকে জাহান্নামের মাঝখানে দেখতে পাবে।

( 56 ) সে বলবে, আল্লাহর কসম, তুমি তো আমাকে প্রায় ধ্বংসই করে দিয়েছিলে।

( 57 ) আমার পালনকর্তার অনুগ্রহ না হলে আমিও যে গ্রেফতারকৃতদের সাথেই উপস্থিত হতাম।

( 58 ) এখন আমাদের আর মৃত্যু হবে না।

( 59 ) আমাদের প্রথম মৃত্যু ছাড়া এবং আমরা শাস্তি প্রাপ্তও হব না।

( 60 ) নিশ্চয় এই মহা সাফল্য।

( 61 ) এমন সাফল্যের জন্যে পরিশ্রমীদের পরিশ্রম করা উচিত।

( 62 ) এই কি…

…লেখাটি এখানে সংক্ষেপে দেওয়া হলো।
